# Screen mocks

Clickable mocks of every Triaged screen, with synthetic Northwind Devices data. View them on the shared canvas: <https://claude.ai/artifact/3GhCHxN5Ja4hDyYa4epwdu>.

These files are the canvas source (`.dc.html` design components plus `canvas.json`). They need the canvas runtime to render, so open the link rather than the files. Each screen names the platform that will serve it:

| Mock | Screen | Platform |
| --- | --- | --- |
| `Main.dc.html` | Screen map | — |
| `Pipeline.dc.html` | Pipeline | Grafana |
| `Trace.dc.html` | Ticket trace | Langfuse |
| `Review.dc.html` | Review queue | Appsmith |
| `Rules.dc.html` | Rules | Appsmith + Git |
| `SLA.dc.html` | SLA | Grafana |
| `Insights.dc.html` | Insights | Grafana + Langfuse |
| `Admin.dc.html` | Admin | Appsmith + Keycloak |
